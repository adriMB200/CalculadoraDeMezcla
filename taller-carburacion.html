05 / MOTOR 2T Y 4T CON CARBURADOR

Asistente de carburación

Compara la densidad aproximada del aire entre tu carburación de referencia y el lugar donde circulas. No calcula chiclés de forma automática: la numeración varía entre fabricantes y el ajuste depende del carburador, aguja, combustible y motor.

Compara altitud y temperatura para ver cómo cambia la densidad del aire.

Una mezcla excesivamente pobre puede sobrecalentar o dañar el motor. No uses este cálculo como autorización para modificar chiclés ni para hacer pruebas sostenidas a plena carga. Comprueba el manual específico y el estado mecánico.
